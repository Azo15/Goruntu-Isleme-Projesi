# Katkıda Bulunma Rehberi / Contributing Guidelines

Projeye katkıda bulunmak istediğiniz için teşekkürler! / Thank you for considering contributing!

## 🇹🇷 Adımlar
1. Bu depoyu **Fork** edin.
2. Yeni bir geliştirme dalı açın (`git checkout -b feature/yeni-ozellik`).
3. Değişikliklerinizi commit edin (`git commit -m 'feat: Yeni özellik eklendi'`).
4. Dalınızı push edin (`git push origin feature/yeni-ozellik`).
5. Bir **Pull Request (PR)** oluşturun.

## 🇬🇧 Steps
1. **Fork** the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'feat: Add amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a **Pull Request (PR)**.
